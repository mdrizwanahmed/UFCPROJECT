About UFC

The Ultimate Fighting Championship (UFC) is the world's premier mixed martial arts organization. It brings together elite fighters from different combat disciplines such as boxing, wrestling, Brazilian jiu-jitsu, and Muay Thai.

This web project is developed as part of a Git Bash and GitHub hands-on assignment. The focus of the project is to demonstrate version control concepts such as branching, merging, and conflict resolution.
